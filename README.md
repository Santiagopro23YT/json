# Mini proyecto JSON

Aplicativo web académico desarrollado por **Samuel Santiago Ramirez Fierro** para
Análisis y Desarrollo de Software (ADSO), ficha 3407799.

El aplicativo permite registrar y consultar programas, fichas, aprendices,
instructores, cursos, matrículas y calificaciones. Su objetivo es organizar el
flujo académico desde la creación de un programa hasta el registro del resultado
de una matrícula.

## Tecnologías

- HTML, CSS y JavaScript nativo con módulos ES.
- Node.js, npm y JSON Server para servir la interfaz, exponer la API REST y guardar los datos.
- Arquitectura Modelo–Vista–Controlador (MVC).

## Ejecución rápida

Desde la raíz del repositorio, ejecuta:

```text
cd server
npm ci
npm start
```

Abre `http://localhost:3000/` en el navegador.
